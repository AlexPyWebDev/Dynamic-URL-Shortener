# Dynamic URL Shortener 🌐

A modern and interactive URL shortener web application built with **Python (Flask)**. It features a dynamic UI that transitions background visuals upon successful link generation.

## Features
- Shortens long URLs into unique, random 6-character codes.
- In-memory database dictionary for fast routing and redirection.
- Dynamic visual transition effect (from night to day theme) upon submitting a link.
- Clean backend logic and responsive frontend layout.

## Technologies Used
- Python 3.x
- Flask Framework
- HTML5 / CSS3 (with smooth CSS transitions)

## Installation & Running
1. Install Flask via terminal:
   \`\`\`bash
   pip install flask
   \`\`\`
2. Run the application:
   \`\`\`bash
   python app.py
   \`\`\`
3. Open your browser and navigate to `http://127.0.0.1:5000`.
